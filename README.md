# 🏪 Laugeed Store

Веб-магазин для скачивания твоих приложений. Работает на GitHub Pages.

---

## Структура проекта

```
LaugeedStore/
├── index.html       — Главная страница (список приложений)
├── app.html         — Страница приложения (?id=forest)
├── updates.html     — Страница обновлений
├── style.css        — Все стили
├── script.js        — Логика сайта
├── apps.json        — ДАННЫЕ ПРИЛОЖЕНИЙ (редактировать здесь)
├── /icons           — Иконки приложений (.svg / .png)
└── /apps            — Файлы для скачивания (.exe / .zip)
```

---

## Как добавить новое приложение

Открой `apps.json` и добавь объект в массив `apps`:

```json
{
  "id": "myapp",
  "name": "Моё приложение",
  "tagline": "Короткое описание",
  "version": "1.0.0",
  "releaseDate": "2026-03-11",
  "description": "Полное описание приложения.",
  "icon": "icons/myapp.svg",
  "download": "apps/myapp.exe",
  "price": {
    "USD": 10,
    "RUB": 950,
    "UAH": 410,
    "EUR": 9
  },
  "platform": "Windows 10/11",
  "size": "20 MB",
  "category": "Утилиты",
  "features": [
    "Функция 1",
    "Функция 2"
  ],
  "changelog": [
    {
      "version": "1.0.0",
      "date": "2026-03-11",
      "changes": ["Первый релиз"]
    }
  ]
}
```

Положи иконку в `/icons/`, файл в `/apps/` — готово.

---

## Как обновить версию

В `apps.json`:
1. Измени `"version"` на новую
2. Добавь новый объект в начало `"changelog"`:

```json
{
  "version": "1.1.0",
  "date": "2026-04-01",
  "changes": [
    "Исправлены ошибки",
    "Новая функция X"
  ]
}
```

3. Замени файл в `/apps/` на новый

## Как загрузить на GitHub Pages

1. Зарегистрируйся на [github.com](https://github.com)
2. Создай репозиторий: `New repository` → имя `laugeed-store` → Public
3. Загрузи все файлы через `Add file → Upload files`
4. Перейди в `Settings → Pages → Source: main branch / root`
5. Сайт будет доступен по адресу:
   `https://ТВО_ЛОГИН.github.io/laugeed-store/`

## Как принимать платежи (продажа за $10)

GitHub Pages бесплатный — платежи он не обрабатывает.
Используй один из этих сервисов:

### Gumroad (проще всего)
1. Зарегистрируйся на [gumroad.com](https://gumroad.com)
2. Создай продукт → загрузи .exe → поставь цену $10
3. Замени ссылку `"download"` в apps.json на ссылку Gumroad
4. Gumroad сам конвертирует валюту и принимает карты/PayPal

### LiberaPay / Boosty (для России)
- [boosty.to](https://boosty.to) — российский аналог Patreon
